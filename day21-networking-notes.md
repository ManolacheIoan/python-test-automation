# Day 21 - Networking Basics

## What I did
- Wrote a ping utility to check host reachability
- Built a simple port scanner using Python sockets
- Wrote automated pytest tests validating network connectivity 
  and port status

## Why this matters
Understanding networking fundamentals (ping, TCP ports, sockets) 
is valuable for QA/test automation roles involving distributed 
systems, infrastructure testing, or DevOps-adjacent responsibilities. 
It also connects directly to CAN bus work (Day 7) - both involve 
testing communication between systems, just at different network layers.
